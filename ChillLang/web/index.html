ChillLang Compiler Phase Pipeline

        

        
      


      

        
ChillLang implements all classical compiler phases as taught in academic compiler construction:


        

          

            
1. Lexical Analysis (Scanner)

            
DFA-based scanner parses characters into categorized tokens: Keywords (make, task, give, say, check, repeat), Identifiers, Operators, and Literals with line/col tracking.

          

          

            
2 & 3. Syntax Analysis & AST

            
Recursive descent LL(1) parser with precedence climbing constructs a complete Abstract Syntax Tree, recovering safely at statement synchronization boundaries.

          

          

            
4 & 5. Semantic Analysis & Symbols

            
Multi-level scoped symbol table tree enforces declaration-before-use, checks for duplicate identifiers, verifies task arity, and types.

          

          

            
6. Intermediate Code Gen (TAC)

            
Lowers high-level AST constructs into classical linearized Three-Address Code (TAC) quadruples with temporaries (t1, t2) and branch labels.

          

          

            
7. Code Optimization

            
Machine-independent passes: Constant Folding (10 + 5 * 2 ➔ 20) and Algebraic Simplification (x * 0 ➔ 0, x + 0 ➔ x) with Dead Temporary Elimination.

          

          

            
8 & 9. Target Codegen & Runtime

            
Multi-target emission: ECMAScript 2024, WebAssembly (WAT), LLVM-IR, and ChillVM Stack Bytecode with sandboxed execution.
